创业信息选择论

发表于2026-09-11|更新于2026-09-12|创业

用信息论和贝叶斯思维判断创业项目：从“不确定”到“值得下注”

概率告诉你现在有多大把握。

熵告诉你现在有多不确定。

信息增益告诉你什么信息最有价值。

贝叶斯更新告诉你拿到新信息以后应该如何修改判断。

期望值告诉你这个项目值不值得下注。

创业最困难的地方，不是没有机会，而是机会永远不会以“确定答案”的形式出现。

你很少会遇到这样一个项目：

“市场规模已经确定，用户已经确定，价格已经确定，竞争对手已经确定，利润已经确定，请放心投资。”

现实中的创业更接近：

“这里似乎有一个需求，但不知道有多少人需要；似乎有人愿意购买，但不知道愿意支付多少钱；似乎能够赚钱，但不知道获客成本是多少。”

因此，创业本质上可以被理解为一个在不确定性中进行决策的问题。

这也是概率论、信息论和贝叶斯方法能够进入创业分析的地方。

一、创业首先面对的不是“赚钱”，而是“不确定性”

假设你准备做一个项目。

在项目开始之前，你可能有很多问题：

  • 有没有真实需求？
  • 用户是谁？
  • 用户为什么购买？
  • 用户愿意支付多少钱？
  • 产品是否真的能够解决问题？
  • 获客成本是多少？
  • 毛利率是多少？
  • 用户会不会复购？
  • 竞争对手会不会迅速进入？
  • 这个市场是不是已经过度竞争？

这些问题共同构成了项目的不确定性。

可以把一个项目的未来状态简单表示为：

[
X={成功,\ 一般,\ 失败}
]

你不知道未来究竟会落在哪个状态。

于是，你开始产生概率判断：

[
P(成功)=0.2
]

[
P(一般)=0.5
]

[
P(失败)=0.3
]

这里的概率不是“宇宙中客观存在的数字”。

它首先代表：

在当前信息条件下，你对不同未来状态的信念程度。

这点非常重要。

创业者不是在寻找一个神秘的“真实成功率”。

创业者真正需要做的是：

根据目前拥有的信息，形成一个可以被新证据修正的概率判断。

二、概率：告诉你“现在有多大把握”

概率是整个框架的第一层。

例如你准备做一个小型食品项目。

你当前判断：

[
P(成功)=30\%
]

这意味着什么？

并不是：

“这个项目100次一定成功30次。”

而是：

“按照目前掌握的信息，我对这个项目成功的信心大约处于30%的水平。”

因此，概率其实是一种信念刻度。

1. 不要直接判断“项目成功概率”

一个常见错误是直接问：

“这个项目成功率是多少？”

这个问题太大。

更好的做法是把成功拆开。

例如：

[
S=D\times P\times C\times M
]

其中：

  • (D)：需求成立
  • (P)：产品成立
  • (C)：客户获取成立
  • (M)：商业模型成立

更严格地写成条件概率：

[
P(S)
=
P(D)
P(P|D)
P(C|D,P)
P(M|D,P,C)
]

这比直接拍脑袋给出一个“成功率”合理得多。

三、为什么创业项目的概率不能凭空产生？

假设你说：

“我觉得这个项目成功率70%。”

那么接下来应该问：

为什么是70%，而不是30%？

概率必须有来源。

可能来源于：

1. 历史经验

你以前做过类似项目。

2. 行业统计

这个行业过去大量项目的成功率。

3. 相似案例

与你的项目具有相似商业结构的案例。

4. 当前证据

已经存在的销售、咨询、搜索、订单等数据。

5. 主观先验

即使没有任何调查，你也可以根据常识、经验和已有知识形成初始判断。

但最后一种应该明确标记为：

先验，而不是事实。

四、没有调查的时候，真正应该使用的是“先验概率”

假设你没有做市场调查。

你仍然可以说：

[
P(H)=20\%
]

这里的 (H) 是：

“项目最终达到预期盈利目标。”

这个20%就是你的：

[
Prior
]

即：

先验概率。

它不是最终答案。

它只是：

“在没有新证据之前，我暂时相信多少？”

创业真正有价值的地方，是后面的更新。

五、熵：告诉你“现在到底有多不确定”

概率解决的是：

我有多大把握？

信息论进一步提出：

这种不确定性到底有多大？

这就是熵。

对于离散随机变量：

[
H(X)
=
-\sum_i p_i\log_2p_i
]

它衡量的是：

在当前概率分布下，你对未来结果的不确定程度。

六、为什么“50%成功、50%失败”比“99%成功、1%失败”更不确定？

假设项目A：

[
P(成功)=0.5
]

[
P(失败)=0.5
]

项目B：

[
P(成功)=0.99
]

[
P(失败)=0.01
]

两者都有“成功”和“失败”。

但是A明显更不确定。

因为你几乎不知道未来会发生什么。

而B虽然也不是100%成功，但你已经非常有把握。

用二元熵：

[
H(p)
=
-p\log_2p
-(1-p)\log_2(1-p)
]

当：

[
p=0.5
]

熵最大。

当：

[
p\rightarrow1
]

或者：

[
p\rightarrow0
]

熵下降。

因此：

概率越集中，预测越确定；概率越平均，不确定性越高。

七、创业中的“熵”是什么？

可以把它理解成：

你对这个项目未来究竟会发生什么，有多不了解。

例如：

项目A

你已经知道：

  • 有稳定客户
  • 已经有订单
  • 毛利率明确
  • 获客成本明确
  • 复购率明确

这个项目的熵比较低。

项目B

你只知道：

“我感觉这个东西应该有人喜欢。”

但不知道：

  • 谁买
  • 为什么买
  • 多少钱买
  • 从哪里买
  • 怎么获客
  • 能不能盈利

这个项目的熵非常高。

八、创业的第一性问题不是“我要不要做”

而应该是：

我现在对这个项目究竟有多不确定？

这是一个非常大的思维转变。

因为：

“不知道”

和

“成功概率低”

是两回事。

例如：

[
P(成功)=20\%
]

可能意味着：

你已经知道这个项目很难。

也可能意味着：

你其实什么都不知道，只是随便估了20%。

第二种情况真正的问题不是项目差。

而是：

项目的信息熵太高。

九、信息增益：告诉你“什么信息最值得获取”

这是整个创业框架中最有价值的部分。

假设你有五个未知问题：

  1. 用户是谁？
  2. 用户愿意多少钱购买？
  3. 哪个渠道最好？
  4. 产品哪个版本最好？
  5. 用户是否愿意复购？

你不可能同时解决所有问题。

于是出现一个问题：

下一步应该调查什么？

信息论给出的思路是：

寻找能够最大程度降低不确定性的信息。

这就是：

[
Information\ Gain
]

信息增益。

通常写成：

[
IG(X;Y)=H(X)-H(X|Y)
]

意思是：

获取信息 (Y) 以后，对变量 (X) 的不确定性下降了多少。

十、把信息增益翻译成创业语言

假设你想做一个产品。

现在你有三个未知问题。

问题A

用户喜欢什么颜色？

问题B

用户愿意支付多少钱？

问题C

用户到底有没有购买需求？

三个问题都能调查。

但哪个信息价值最高？

显然通常是C。

因为：

如果根本没人需要，你研究颜色没有意义。

因此创业中的信息价值应该考虑：

[
价值
\approx
\text{不确定性减少程度}
\times
\text{对决策的重要程度}
]

十一、真正应该寻找的是“高信息增益问题”

例如：

“你喜欢这个产品吗？”

通常信息增益不高。

因为很多人会回答：

“挺好的。”

但：

“如果今天售价79元，你愿意买吗？”

信息价值明显更高。

进一步：

“如果79元不买，什么价格你会购买？”

又增加了一层信息。

而最强的信息之一往往是：

真实支付行为。

因此：

[
观察行为
>
询问态度
]

通常是创业调查中的重要原则。

十二、贝叶斯更新：拿到新信息以后，应该怎样改变判断？

现在进入第四个概念：

贝叶斯更新。

创业不是：

“我已经做出了判断。”

而是：

“我现在有一个判断，如果新证据出现，我应该如何修改它？”

贝叶斯公式：

[
P(H|E)
=
\frac{P(E|H)P(H)}
{P(E)}
]

其中：

  • (H)：项目成功
  • (E)：新证据
  • (P(H))：原来的判断
  • (P(H|E))：看到证据以后新的判断

换句话说：

[
\boxed{
新判断
=
旧判断
+
新证据
}
]

当然数学上不是简单相加，而是按照贝叶斯公式重新计算。

十三、举一个创业例子

假设你准备做一个产品。

初始判断：

[
P(H)=20\%
]

也就是：

你认为项目成功概率大约20%。

后来你发现：

已经有很多消费者主动搜索类似产品。

这是一条证据。

假设：

[
P(E|H)=0.8
]

也就是说：

如果这个项目真的有市场，那么出现这种搜索行为的概率很高。

而如果项目没有市场：

[
P(E|\neg H)=0.2
]

那么这条证据就很有价值。

十四、贝叶斯的真正意义：允许你“改变主意”

这是创业中特别重要的一点。

很多创业失败并不是因为最初判断错误。

而是：

证据已经证明原来的判断不成立，但创业者拒绝修改判断。

例如：

最初：

[
P(H)=60\%
]

然后连续出现：

  • 用户不购买
  • 广告点击低
  • 复购率低
  • 毛利率低
  • 获客成本高

正常的贝叶斯思维应该让：

[
60\%
\rightarrow40\%
\rightarrow20\%
\rightarrow8\%
]

但很多创业者会变成：

“现在只是市场还没教育好。”

然后继续投入。

这实际上是：

拒绝进行概率更新。

十五、贝叶斯思维要求创业者允许自己被证据推翻

一个成熟的创业判断应该是：

“这是我目前最好的判断。”

而不是：

“这是我的项目，所以它一定会成功。”

这两个句子差别非常大。

前者允许：

[
P(H)
\rightarrow
P(H|E)
]

后者则容易进入：

沉没成本 + 确认偏误 + 自我证明。

十六、信息增益和贝叶斯更新其实是一前一后的

两者可以连接起来：

[
\boxed{
寻找高信息增益证据
\rightarrow
获得证据
\rightarrow
贝叶斯更新
}
]

所以：

信息增益解决“下一步应该知道什么”。

而：

贝叶斯解决“知道以后怎么办”。

十七、期望值：最后才回答“值得不值得做”

即使你已经知道：

[
P(成功)=10\%
]

仍然不能直接得出：

“不要做。”

因为创业决策还需要考虑：

成功以后赚多少，失败以后亏多少。

这就是期望值。

最简单的二元情况：

[
EV
=
P(S)R
-
P(F)L
]

其中：

  • (P(S))：成功概率
  • (R)：成功收益
  • (P(F))：失败概率
  • (L)：失败损失

十八、一个简单例子

项目成功概率：

[
P(S)=10\%
]

成功收益：

[
R=100万元
]

失败概率：

[
P(F)=90\%
]

失败损失：

[
L=5万元
]

那么：

[
EV
=
0.1\times100
-
0.9\times5
]

[
=10-4.5
]

[
=\boxed{5.5万元}
]

也就是说：

虽然成功概率只有10%，但这个下注的期望价值仍然是正的。

十九、反过来，高成功率项目也可能不值得做

假设：

[
P(S)=80\%
]

成功赚：

[
2万元
]

失败损失：

[
10万元
]

那么：

[
EV
=
0.8\times2
-
0.2\times10
]

[
=1.6-2
]

[
=-0.4万元
]

所以：

80%的成功概率，不代表值得做。

创业决策不能只看概率。

必须同时看：

[
\boxed{
概率\times收益\times损失
}
]

二十、真正的创业决策函数

因此，一个创业项目至少应该同时看三个东西：

[
\boxed{
\text{不确定性}
+
\text{成功概率}
+
\text{收益/损失结构}
}
]

可以进一步形成：

[
\boxed{
Decision
=
f(P,\ H,\ EV)
}
]

其中：

  • (P)：成功概率
  • (H)：不确定性
  • (EV)：期望价值

二十一、但是创业还有一个经常被忽略的变量：实验成本

这是创业和纯粹赌博最大的区别。

假设一个项目：

[
P(S)=5\%
]

看起来很低。

但如果：

只需要500元就可以测试。

那么它可能值得测试。

反过来：

[
P(S)=50\%
]

但是：

必须先投入100万元才能知道市场是否存在。

这就完全不同了。

因此应该把：

[
\text{实验成本}
]

纳入决策。

二十二、于是出现一个更完整的创业公式

可以把一次创业实验理解成：

[
\boxed{
实验价值
=
期望决策改善
-
实验成本
}
]

如果实验能够显著改变你的决策，那么它的价值就很高。

例如：

你现在不知道一个产品有没有需求。

有两个方案。

方案A

投入：

[
10000元
]

做完整产品。

方案B

投入：

[
500元
]

做20个样品，测试真实购买。

如果B能够让你判断：

“这个市场值得继续。”

或者：

“这个市场应该立即放弃。”

那么B的信息价值可能远远超过500元。

二十三、这就是“最小成本获得最大信息”

可以进一步写成：

[
\boxed{
Information\ Efficiency
=
\frac{Information\ Gain}
{Experiment\ Cost}
}
]

即：

单位成本获得的信息增益。

这实际上是非常强的创业原则。

二十四、创业者真正应该优化的，不只是利润

传统商业思维容易形成：

收入 → 成本 → 利润。

而创业早期还应该增加一层：

信息。

于是：

[
\boxed{
资金
\rightarrow
实验
\rightarrow
信息
\rightarrow
概率更新
\rightarrow
决策
\rightarrow
资金
}
]

创业者是在一个循环中不断学习。

二十五、把整个创业过程看成一个“概率更新系统”

假设你开始时：

[
P(S)=10\%
]

然后：

第一条证据

发现用户确实存在：

[
10\%\rightarrow18\%
]

第二条证据

发现用户愿意付目标价格：

[
18\%\rightarrow35\%
]

第三条证据

发现获客成本过高：

[
35\%\rightarrow22\%
]

第四条证据

找到低成本渠道：

[
22\%\rightarrow48\%
]

第五条证据

出现大量复购：

[
48\%\rightarrow67\%
]

你会发现：

创业并不是一次性决定“做还是不做”。

而是：

[
10\%
\rightarrow18\%
\rightarrow35\%
\rightarrow22\%
\rightarrow48\%
\rightarrow67\%
]

不断更新。

二十六、这也是为什么创业者应该记录自己的概率判断

一个非常实用的方法：

每次做重要决策时记录：

项目 当前判断
市场存在 70%
用户愿意购买 40%
能做到目标成本 60%
能找到客户 30%
最终盈利 20%

然后写下：

“什么证据出现以后，我会把这个概率提高？”

以及：

“什么证据出现以后，我会把这个概率降低？”

这一步非常重要。

因为它迫使你明确：

什么东西能够改变我的观点？

二十七、这其实是在建立一个“商业信念模型”

例如：

假设

ADHD科普网站最终能够形成稳定收入。

当前：

[
P(H)=15\%
]

支持证据

  • 搜索需求存在
  • 用户持续阅读
  • 有人咨询
  • 有人愿意购买资料

反对证据

  • 阅读量低
  • 用户不愿付费
  • 广告收入不足
  • 竞争网站很多

于是每获得一条证据：

[
P(H)\rightarrow P(H|E)
]

这就是一个动态的商业模型。

二十八、一个真正成熟的创业问题应该这样问

不要问：

“这个项目好不好？”

而应该问：

第一问

我现在认为它成功的概率是多少？

第二问

我为什么认为是这个概率？

第三问

我现在最大的不确定性是什么？

第四问

什么信息能够最大幅度降低这个不确定性？

第五问

获得这个信息需要多少钱？

第六问

如果获得不同结果，我的概率会怎么改变？

第七问

在不同结果下，这个项目的期望价值是多少？

第八问

什么时候应该继续，什么时候应该停止？

这已经从“创业直觉”变成了一个相对严格的决策系统。

二十九、五个概念最终形成一条完整链条

可以把整个模型压缩成：

[
\boxed{
概率
\rightarrow
熵
\rightarrow
信息增益
\rightarrow
贝叶斯更新
\rightarrow
期望值
}
]

分别回答五个问题。

① 概率

我现在相信它成功的可能性有多大？

P(H)
]

② 熵

]

③ 信息增益

[
IG=H(X)-H(X|Y)
]

④ 贝叶斯更新

拿到新信息以后，我应该把概率改成多少？

[
P(H|E)
=
\frac{P(E|H)P(H)}
{P(E)}
]

⑤ 期望值

]

三十、最重要的一个转变：创业不是预测，而是学习

如果把这套理论理解到最后，会发现：

创业并不是要求你一开始就知道答案。

恰恰相反。

创业允许你：

不知道。

但是要求你：

知道自己不知道什么。

进一步要求：

知道如何以最低成本减少这种不知道。

再进一步：

获得信息以后，愿意改变自己的判断。

因此：

[
\boxed{
优秀创业者
\neq
预测最准的人
}
]

更接近：

[
\boxed{
优秀创业者
=
能够最快、最低成本地降低关键不确定性的人
}
]

三十一、最终可以形成一个“创业信息论循环”

三十二、一个最简洁的创业决策框架

以后遇到任何项目，都可以拿出一张纸，只写这六项：

  1. 我的先验概率
  2. 最大的不确定性
  3. 我最缺的信息
  4. 获取它的最低成本
  5. 得到不同结果以后，概率如何变化
  6. 不同结果下的期望收益

然后才问：

现在应该下注、继续实验、改变方向，还是放弃？

结语：创业的本质，是管理不确定性

香农信息论原本研究的是通信中的信息传递。

创业则面对另一种“通信问题”：

市场是发送者，创业者是接收者。

市场不断发出信号：

搜索
点击
咨询
购买
复购
退款
推荐
抱怨
放弃

创业者的问题不是：

“我能不能预测市场？”

而是：

“我能不能从这些充满噪声的信号中提取出真正有价值的信息？”

因此：

而：

最终，一个真正成熟的创业者不会把自己的项目当成一个需要“证明正确”的答案。

而会把它当成一个需要不断更新的假设：

“这是我目前认为最可能正确的模型。现在，我需要找到下一条最有价值的信息。”

这也是信息论从数学走向商业实践时，最值得掌握的思维方式。
